# Zoho Analytics (zoho-analytics)

Zoho Analytics is a business intelligence and self-service analytics platform that provides a REST API for managing workspaces, views, reports, dashboards, data import and export, and sharing analytics content. The API enables ISVs, developers, and system integrators to embed powerful reporting and analytical capabilities into their applications. It supports OAuth 2.0 authentication, regional endpoints across eight data centers, and provides SDKs for Java, C#, Python, PHP, Go, and Node.js.

## APIs

### Zoho Analytics API

REST API v2 for Zoho Analytics providing programmatic access to workspaces, views, reports, dashboards, bulk data import and export, metadata management, embedding, sharing, and user management operations.

- **Human URL:** [https://www.zoho.com/analytics/api/](https://www.zoho.com/analytics/api/)
- **Base URL:** `https://analyticsapi.zoho.com/restapi/v2`
